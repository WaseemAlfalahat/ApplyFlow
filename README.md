
# ApplyFlow

A full-stack job application management platform for
students and job seekers.

## Project Status

🚧 In development — Milestone 01

## Planned Features

- Secure user registration and login
- Job application tracking
- Kanban board
- Interview and deadline management
- Analytics dashboard
- Search and filtering
- CSV export
- User-specific data protection

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend
- C#
- ASP.NET Core 10 Web API
- Entity Framework Core 10
- ASP.NET Core Identity

### Database
- Azure SQL Database (SQL Server compatible)

### Testing and DevOps
- Docker
- GitHub Actions
- xUnit
- Vitest
- Playwright

## Architecture

React SPA → ASP.NET Core REST API → Azure SQL
